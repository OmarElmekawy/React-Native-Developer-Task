# React-Native-Developer-Task
instruction to open the App:

Download the APK file.

Launch the Android emulator.

Transfer the APK file to the emulator and install it

I used several key features of React Native in this project. React Navigation was implemented to handle navigation between screens. HTTP requests were used to establish communication between the front end and a mock API. Redux was utilized for managing global application state. User inputs are validated before sending credentials to the backend, and error handling is implemented to manage any errors returned from the backend.
